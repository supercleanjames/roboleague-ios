# RoboLeague iOS

Virtual Robot Football League — iOS App

## Overview
RoboLeague brings the world's first AI-powered robot football league to your iPhone. Watch games, track stats, and own your own team.

- **Participant:** $10/season
- **Team Owner:** $10,000 license
